# WebDAV 使用指南

CipherNest 提供两项独立的 WebDAV 功能：**远端备份**保存完整加密保险库及历史恢复点，供以后整库恢复；**多设备同步**在设备间合并条目修改并处理冲突。自动备份不会让其他设备自动取得最新条目。新建或加入的同步配置默认启用自动模式，旧版现有手动配置升级后仍保持手动；可在设置中随时切换。自动同步仅在保险库解锁期间运行。备份文件和同步对象都不要求服务器掌握解密密钥。

仅需在设备故障后找回保险库时，可使用远端备份；需要在多台设备上接续编辑时，应配置双向同步，并继续保留独立的备份。

两项功能都要求已存在、以 `/` 结尾的 `https://` WebDAV 目录，以及具有相应读写权限的账号。建议为备份和同步分别使用专用目录与可单独撤销的应用密码。服务器证书必须受本机信任、未过期，且与所用域名或 IP 匹配；CipherNest 不接受 HTTP、跳过证书验证或自动跟随重定向。

## 远端加密备份

1. 在解锁后的“设置 → 加密备份”配置备份目录、用户名和应用专用密码。连接测试会查询目录，并创建、读回、删除随机测试文件；账号须有 `PROPFIND`、`PUT`、`GET`、`DELETE` 权限。可启用保存后的自动上传。
2. 启用自动上传后，本机成功保存的最新版本会在后台上传，短时间内连续保存会合并；上次未确认上传的版本会在下次解锁时重试。也可点击“立即上传加密备份”手动创建副本。应用为每份备份生成带随机标识的 `.cnvault` 文件名，上传后读回并核对内容。失败不会撤销本机保存，可在设置页查看警告和最近上传状态。WebDAV 备份不更新多设备同步的远端 head，也不会合并条目。
3. 需要恢复时，在设置或锁定页查看远端备份，选择文件下载，输入**该份备份创建时**的主密码并核对只读预览；确认后替换本机保险库。新设备可在锁定页输入 WebDAV 凭据，并选择在恢复成功后加密保存该连接、启用自动备份。取消或验证失败不会保存连接。

WebDAV 远端备份只需要普通目录读写行为，不要求强 ETag、`If-Match` 或 `If-None-Match`。每次上传使用新文件名，应用不会主动覆盖以前上传的备份；服务端仍可能修改、删除或回滚文件。当前不会自动清理远端历史，请关注容量，并另外保存异盘或离线加密备份。远端备份沿用原保险库的主密码保护，主密码修改后旧备份仍需旧密码。详见[备份与恢复](BACKUPS.md)。

## 多设备同步配置要求

1. 在 WebDAV 服务器上创建专用目录，并为账号授予该目录的读取、创建、修改和删除权限。建议使用可单独撤销的应用专用密码。
2. 输入指向**已存在目录**的完整 `https://` 地址，路径以 `/` 结尾。用户名、密码应填在独立输入框内，不要写进地址。
3. 确认填写的端口实际提供 HTTPS，服务器在 TLS 握手中发送所需的中间证书（如有），且证书受本机信任、未过期，并与地址中的域名或 IP 匹配。CipherNest 不接受 HTTP，也不会忽略证书错误或自动跟随重定向。
4. 服务器须支持 WebDAV 集合查询、强 ETag、`If-Match` 和 `If-None-Match` 条件写入，以及普通 `DELETE`。CipherNest 会在连接和提交前使用随机测试对象核验这些行为；不满足要求的服务器不能用于同步。测试会让两个使用同一 ETag 的条件写入竞争，要求只有一个成功，并确认清理后的测试对象已删除。

端口号由服务器配置决定。绿联 NAS 的[默认 WebDAV 端口](https://support.ugnas.com/detail/article/zh-CN/82)为 HTTP 5005、HTTPS 5006，但管理界面允许修改，不能仅凭端口号判断协议。

## 创建、加入和日常同步

- **创建同步空间**：输入 WebDAV 目录、用户名和密码；服务器支持时，建议使用可单独撤销的应用专用密码。创建成功后，将 `CN1.` 开头的同步恢复码保存在 WebDAV 目录之外，并与 WebDAV 密码分开保管。
- **加入已有空间**：在新设备上输入同一目录、具备该目录读写权限的账号及完整同步恢复码，先核对远端概览。本机已有条目或删除记录时，默认选择“合并”；选择“以远端替换本机”必须再次确认，替换前应另存备份。预览后若本机或远端内容发生变化，需重新预览。
- **日常同步**：新建或加入空间后默认自动双向同步；旧版现有手动配置升级后仍保持手动。可在“设置 → 多设备加密同步”切换模式，也可随时点击“立即同步”。自动模式在解锁后、本地保存后约 3 秒检查远端，解锁期间约每 90 秒检查一次。锁定时停止新的同步检查。临时网络失败会显示警告并定期重试；同步历史或本地检查点无法安全验证、远端提交结果无法确认时，自动同步暂停，应先保留本机备份、核对其他设备，再执行手动同步。保存、删除或收藏变更后，状态栏会提示本机修改待同步；若本机同步状态无法确认，应用不会把旧状态显示为已同步。两台设备同时修改同一条目时，应用会保留冲突副本：通常添加“同步冲突”标签；原条目已有 20 个标签时保留全部标签，以标题末尾的“（同步冲突）”标记识别。设置页显示待核对数量并提供查看入口。核对后可移除冲突标签、修改标题末尾标记，或删除多余副本。自行设置相同标记的条目也可能进入审阅列表。

创建或加入失败后，设置页会保留错误提示和重试入口。重试只预填本次会话中的目录地址与用户名；应用专用密码和同步恢复码必须重新输入。如果创建请求可能已写入服务器，但本机没有取得恢复码，请核对本机状态，并使用新的空目录重新创建；不要清理其他设备正在使用的目录。

同步恢复码用于加入同一同步空间，**不能重置或替代本地主密码**。停止某台设备的同步只清除该设备的本地配置，不会删除服务器上的加密对象。

## 绿联 NAS 的端口与证书

绿联 WebDAV 默认使用 5005 提供 HTTP、5006 提供 HTTPS，但支持自定义端口。如果已经将 HTTPS 配置在 5005，可以继续使用该端口；请以服务的实际配置为准。

绿联默认证书可能是自签证书，且未包含访问地址所需的主题备用名称（SAN）。将证书导入系统信任列表只能解决信任链问题，不能解决地址不匹配。通过 IP 连接时，证书须包含相同的 `iPAddress` SAN；通过域名连接时，证书须包含相同的域名，并在 CipherNest 中填写该域名。[TLS 服务身份规范](https://www.rfc-editor.org/rfc/rfc9525.html)规定了证书身份匹配要求。

在绿联 NAS 的“控制面板 → 安全性 → 证书”中导入覆盖实际访问域名或 IP 的证书及所需证书链，再通过“服务配置”将证书分配给 WebDAV 对应的 HTTPS 服务。导入界面显示中间证书并不保证 WebDAV 服务已在握手中发送它；如仍提示证书链错误，应核对该端口实际发出的证书链，并重新应用证书配置。使用私有证书颁发机构时，还须在客户端系统中信任其根证书。操作位置参见绿联官方的[证书说明](https://support.ugnas.com/detail/article/zh-CN/107)；WebDAV 的启用和自定义端口位置参见[WebDAV 说明](https://support.ugnas.com/detail/article/zh-CN/82)。

## 常见连接问题

| 现象 | 检查项 |
| --- | --- |
| HTTPS 连接失败或超时 | 核对端口是否实际启用 HTTPS、设备和防火墙是否允许连接、证书链是否受信任，以及证书 SAN 是否覆盖所用域名或 IP。5005 提示仅说明常见默认配置，不表示该端口一定是 HTTP。 |
| 提示 HTTPS 证书链无法验证 | 检查 WebDAV HTTPS 服务实际发送的证书链是否包含站点证书及所需中间证书。部分系统会自动补取中间证书，因而浏览器显示正常也不能证明服务器已发送完整证书链。 |
| 服务端返回 401 或 403 | 核对用户名和应用专用密码，以及账号的 WebDAV 服务权限和目标目录的读写权限。 |
| 集合查询返回 404，或提示地址不是 WebDAV 集合 | 确认目录已存在、路径大小写正确、地址以 `/` 结尾，并且该路径允许 WebDAV 集合查询。远端 head 尚未建立则属于另一种情况，应先创建同步空间或核对恢复码与目录。 |
| 提示服务器不支持安全同步条件 | 检查服务器或反向代理是否保留强 ETag，并正确执行 `If-Match`、`If-None-Match`。若服务器在条件不满足时仍覆盖文件，就不能用于多设备同步；该限制不影响使用普通 WebDAV 远端备份。 |
| 提示远端已被其他设备更新 | 重新执行手动同步，让应用拉取并合并最新快照；核对产生的冲突副本。自动同步遇到无法确认的提交结果时会暂停，需先核对其他设备。 |
| 提示请求可能已修改远端，但本机结果待确认 | 不要连续创建或替换同步空间。先保留本机加密备份和已有恢复码，核对当前设备及另一台可信设备的同步状态，再决定是否重新加入或同步。 |

## 长期离线与删除记录

已配置设备会检查远端更新能否沿父快照链回到本机保存的检查点。一次检查最多追溯 256 个快照，累计时间最多 90 秒。长期离线后若超过任一限制，同步会拒绝继续，以免跳过尚未验证的历史。此时先手动导出本机加密备份，再从仍可信且较新的设备核对远端状态；需要重新加入时，预览并选择合并或替换。重新加入会放弃该设备以前保存的检查点，不能把它当作无风险的报错修复。

删除记录会随同步传递。单个保险库最多容纳 20,000 条删除记录，当前版本不会自动清理这些记录；达到上限后，新删除会被拒绝。继续使用前应先导出并验证备份，再规划迁移到新的保险库和同步空间，核对所有设备上的数据及冲突副本。不要直接修改加密文件或手动删除远端快照。

## 同步与备份的区别

| 功能 | 远端内容 | 另一设备如何取得更新 | 历史恢复与冲突 |
| --- | --- | --- | --- |
| WebDAV 远端备份 | 按版本保存的完整加密 `.cnvault` 文件 | 不会自动更新；须选择备份并验证主密码后整库替换 | 保留多个恢复点，不合并设备修改 |
| WebDAV 多设备同步 | 使用独立同步密钥加密的 snapshot 和 head | 新配置默认在解锁期间自动合并；旧版配置保留手动模式，可切换或立即手动同步 | 合并条目与删除记录，冲突版本保留副本供核对；不提供按版本整库恢复 |

同步会传播删除，不能当作历史备份。远端备份可以提供多个恢复点，但服务器可能删除、延迟或回滚文件；两者都不能代替独立介质上的备份。CipherNest 还在创建保险库、成功保存和解锁时维护本机加密快照：保存前保留旧版本，保存后为当前版本建快照；解锁时已有相同快照则不重复写入。每个保险库的本机快照最多保留 10 份，通常与保险库同盘。

请定期手动导出 `.cnvault` 到独立介质；导出不会覆盖已存在的目标文件。导出的备份不包含本机 WebDAV 备份凭据或同步配置。通过已保存的备份连接恢复时，该连接会保留；使用临时凭据恢复时，可选择在成功后保存本次连接。整库恢复不会延续原 CN1 同步配置或检查点，继续同步须重新加入、核对远端预览，并使用 `CN1.` 恢复码。

更多协议边界见[同步设计](SYNC_DESIGN.md)。
